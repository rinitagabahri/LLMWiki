# Eisenhower Matrix

**Distinguish what's important from what's urgent.**

| | **Urgent** | **Not Urgent** |
|---|---|---|
| **Important** | ✅ Do it now | 📅 Schedule it |
| **Not Important** | 👥 Delegate it | 🗑️ Delete it |

## When to Use It

- You're overwhelmed and everything feels urgent
- You're busy all day but not making progress on what matters
- Weekly/daily planning — sort your tasks into the grid

## Key Insight

The "Important but Not Urgent" quadrant is where growth happens — learning, health, relationships, planning. Most people neglect it because it never screams. Protect time for it.

## Example

### Software Developer's Typical Day

| | **Urgent** | **Not Urgent** |
|---|---|---|
| **Important** | ✅ High customer incident | 📅 Backlog item + AI learning |
| **Not Important** | 👥 Code review (timebox it) | 🗑️ Meetings with no agenda, status emails no one reads |

**The trap:** AI learning feels like it belongs in "Delete" (not urgent, not important to today's work). But it's actually **Important & Not Urgent**. Learning AI is investing in your future relevance. It never screams, so it gets killed by incidents and code reviews unless you protect it.

**The lesson:** The code review *feels* urgent (colleague is waiting) but it's not *your* important work. Give it a timebox. The AI learning *feels* skippable but it's the thing that compounds. Block recurring time for it or it will never happen.

- [[swot-analysis]] — SWOT decides *what* to pursue; Eisenhower manages *how* you execute daily
- [[pareto-principle]] — Eisenhower sorts tasks by importance; Pareto explains *why* that pays off — the vital few important tasks carry most of the value, so they're exactly what belongs in "Do it now" → see [[prioritization]]
- [[bcg-box]] — the portfolio twin: both are 2×2 sorting grids — Eisenhower sorts tasks by urgency/importance, BCG sorts investments by growth/return
- [[esquire-gift-model]] — both fight a default bias: Eisenhower against the pull of urgency, Esquire against the pull of guilt
- [[superficial-knowledge-model]] — both are 2×2 effort/payoff triage grids: Eisenhower sorts tasks, that one sorts what's worth actually learning
